# MindSync Community status

MindSync Community reached its final feature release with `v1.9.0`. The public
code and all previously published packages remain available under the MIT
License that accompanied those releases.

This repository is now feature-frozen:

- no new feature releases are planned;
- feature requests and feature pull requests are not being accepted;
- existing releases remain available without a support or maintenance SLA;
- critical security reports may still be reviewed at the maintainer's
  discretion.

Commercial development continues privately in a separate successor product.
That work has its own licensing and distribution terms and is not part of the
MindSync Community roadmap.
