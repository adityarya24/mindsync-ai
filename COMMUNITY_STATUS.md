# MindSync Community status

This repository is the open core of MindSync. It stays under the MIT License,
and every published package remains available.

What lands here:

- bug fixes and security fixes;
- small improvements to routing, local shared memory and reactive provider cooldowns;
- compatibility updates for new versions of the coding agents it supports.

What doesn't:

- quota handoff and successor checkpoints, pre-emptive usage evaluation,
  Codex reserve warnings, automatic pull requests, and remote queue sync;
- larger coordination features. These belong to MindSync Pro, a commercial
  product developed privately under its own terms (coming soon).

Bug reports and small pull requests are welcome. For a bigger feature idea,
open an issue first so we can say whether it belongs here or in the Platform.
