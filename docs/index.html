MindSync AI is a local-first MCP orchestration layer for coding agents. It turns the CLI already working with you into the lead orchestrator — discovering available workers, routing tasks by capability, supervising execution, and keeping every session aligned through shared focus, events, and durable memory. 

# install
pip install mindsync-ai

# one-time onboarding, then restart your CLI
mindsync setup --mode auto
mindsync doctor

// Why MindSync

Running several capable agents is easy. Keeping them coordinated is the hard part.

Without a shared layer, agents duplicate work, overwrite each other's files, lose decisions between sessions, and make you pick a worker by hand for every single task.

01

Automatic orchestration

The human-facing CLI decides when delegation is actually useful — you stop naming a worker for every task.

02

Capability-based routing

Workers are ranked by task fit, availability, and priority. Every automatic route reports its reason and candidate scores.

03

Conflict prevention

Active file and project focus is visible before work begins, so two agents don't edit the same file blind.

04

Session memory

Decisions, blockers, and durable facts persist per project and replay into the next run instead of being re-explained.

05

Safe process control

Tracked jobs, timeouts, cancellation, and process-tree cleanup — plus optional git worktree isolation per job.

06

Yours, locally

No hosted control plane, no MindSync account. Remote sync is optional and runs through your own SSH host.

// How it works

Your CLI stays in charge.

The orchestrator keeps planning, authorization, integration, and the final answer. Delegated workers receive bounded tasks and cannot recursively delegate through MindSync.

// Session memory

Context that survives the session.

Agents record decisions, blockers, and durable facts per project in local SQLite. The next run gets a bounded, priority-ordered replay: sessions carrying durable facts pack first, then unresolved blockers, then routine history — so noise can never crowd out what mattered.

  • Bounded by a character budget, so a long history never blows up the context window.
  • Conservative redaction of common token, password, and private-key patterns on every write.
  • Dispatch can drive the whole lifecycle automatically — prompts, transcripts, and stdout are never persisted.
  • Human-facing inspection and safe retention, with a dry run before anything is deleted.
# look at what your agents have remembered
mindsync memory stats
mindsync memory list --project my-repo
mindsync memory show <session-id>

# dry run first — nothing is deleted without --yes
mindsync memory prune --older-than-days 30

// Get started

Three commands.

pip install mindsync-ai
mindsync setup --mode auto
mindsync doctor

Setup is idempotent — existing MCP registrations are preserved unless you pass --force, and --dry-run previews every change without touching a file. Requires Python 3.10 or newer.
